# CodeBench — Фреймворк оценки AI-агентов для написания кода

Лёгкий, ориентированный на API фреймворк для оценки AI-агентов написания кода (Claude Code, OpenAI Codex и др.) с песочницей для выполнения кода, обнаружением багов и встроенным веб-интерфейсом.

Построен на базе [OpenCompass](https://github.com/open-compass/opencompass) от [Шанхайской лаборатории искусственного интеллекта](https://www.shlab.org.cn/). Этот проект расширяет оригинальную инфраструктуру оценки современными рабочими процессами AI-агентов, песочницей и оптимизированным API-сервером.

## Возможности

- **Поддержка нескольких провайдеров** — Claude API, Gemini API, OpenAI Responses API, OpenAI Chat Completions
- **Обёртки AI-агентов** — Плагируемая оценка агентов (Claude Code, Codex, пользовательские)
- **Выполнение в песочнице** — Изоляция через подпроцессы и Docker с ограничениями по времени и памяти
- **Обнаружение багов** — Сопоставление паттернов ошибок по регулярным выражениям с классификацией серьёзности и предложениями по исправлению
- **Управление задачами** — Пауза/возобновление/повтор с восстановлением из контрольных точек
- **REST API** — Лёгкий HTTP-сервер (только стандартная библиотека, без дополнительных зависимостей)
- **Веб-интерфейс** — Опциональная тёмная тема (`--enable-ui`)
- **Полное тестирование** — 30+ модульных тестов

## Быстрый старт

```bash
# Установка зависимостей (только для интеграции API агентов)
pip install anthropic google-generativeai openai

# Запуск API-сервера
python -m opencompass.server --port 8000

# С включённым веб-интерфейсом
python -m opencompass.server --port 8000 --enable-ui
```

## API-эндпоинты

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/api/v1/health` | Проверка состояния |
| GET | `/api/v1/models` | Список доступных моделей |
| POST | `/api/v1/evaluate` | Отправить оценку модели |
| POST | `/api/v1/agent/evaluate` | Отправить оценку AI-агента |
| POST | `/api/v1/sandbox/execute` | Выполнить код в песочнице |
| GET | `/api/v1/tasks/{id}` | Запросить статус задачи |
| POST | `/api/v1/tasks/{id}/pause` | Приостановить задачу |
| POST | `/api/v1/tasks/{id}/resume` | Возобновить задачу |
| POST | `/api/v1/tasks/{id}/retry` | Повторить неудачную задачу |
| GET | `/api/v1/tasks/{id}/bugs` | Отчёт об обнаружении багов |
| GET | `/` | Веб-интерфейс (с `--enable-ui`) |
